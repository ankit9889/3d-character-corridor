# 3D Character Corridor

A "choose your preferred corridor" form step with an animated 3D character (Three.js) that lies on the heading, gets up, walks and hops across the form, and sits on the "Golf Course Extension Road" option.

- **1.html** – the corridor page with the character (drag him around, double-click to stop / walk)
- **studio.html** – 3D studio viewer (walk / idle / talk modes, clay / wire views)
- **character_data.js** – textured character model bundled as JS so the page also works when opened from disk
- **character_textured.glb** – same textured model as a regular GLB file
- **1.glb** – original untextured mesh
- **Meshy_AI_character_*_view.png** – reference images used for the texture

Open `index.html` (or `1.html`) in a browser.
